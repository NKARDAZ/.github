## Rules

Follow these rules when engaging in the [Nkardaz](https://github.com/NKARDAZ) community or projects.

### Generative AI

1. **No AI-generated media:** Any kind of media generated by AI is strictly prohibited.
2. **No `Vibecoding`:** Code that fully generated by LLMs, *“vibecoded,”* is not allowed.
3. **AI `Assistance`:** The use of AI as an assistant during `manual coding` is permitted.
