## Rules

Follow these rules when engaging in the [Nkardaz](https://github.com/NKARDAZ) community or projects.

### Contributions

1. **Meaningful Contributions:** Contributions should serve a purpose and fit the project's direction.
2. **Code Quality:** Prefer readable, maintainable code over unnecessary complexity.
3. **Respect Existing Work:** Understand the existing implementation before making changes to it.
4. **Documentation:** Ensure your code is well-documented and easy to understand.

### Generative AI

1. **No AI-generated media:** Any kind of media generated by AI is strictly prohibited.
2. **No `Brainless Vibecoding`:** Relying on LLMs to generate code without understanding how it works is not allowed. Contributors are expected to understand and review the code they submit.
3. **AI `Assistance`:** The use of AI as a coding assistant is fully permitted, provided that contributors understand and review the code they submit.

### Respect & Courtesy

Treat other contributors with respect. Disagreements are fine; personal attacks and deliberate hostility are not.

### Constructive Criticism

Criticism is welcome when it helps improve a project. Explain what you think is wrong and, whenever possible, why.

### Respect for Other People’s Work

Respect the time and effort that goes into a project. Before proposing changes, take a moment to understand the existing work and the reasoning behind it.
